# Worker Presets 0.1.5 release verification

The approved Worker Presets 0.1.4 candidate passed native Save, fresh Continue, Apply, and layout removal in both Human and Undead on Super Fantasy Kingdom 0.8.070. The final Continue preserved the changed staffing and the deletion. The controller review used the same candidate DLL.

## Why 0.1.5

Thunderstore already had a 0.1.4 download with different content. The approved gameplay build was therefore rebuilt with release version 0.1.5.

## Binary comparison

Mono.Cecil compared 192 method definitions across 39 types, including managed instructions, signatures, locals, exception handlers, fields, and assembly references. Both assemblies had zero embedded resources. The comparison allowed version fields in the assembly and BepInEx metadata to move from 0.1.4 to 0.1.5. The normalized managed inventory matched with SHA-256 `bc3a1e902342d11bb9d8ecc82390cd898c84bf1c9591ff2fe8d3ed87dbdda354`.
