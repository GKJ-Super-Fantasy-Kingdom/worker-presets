# Changelog

## 0.1.2

- Show current and proposed staffing in aligned columns, with plot coordinates for duplicate buildings and the number of changes on Apply.
- Show saved building counts in the layout picker and mark workforce shortfalls with the native staffing icon.
- Return one screen at a time with controller Back, keeping the selected layout focused.

## 0.1.1

- Open the slot picker once the game's assignment overlay is visible. Returning to jobs restores controller focus to Worker Presets.
- Place the launcher beside short job labels to leave more room for the building panel at larger UI scales.
- Fit a tall assignment panel between the resource HUD and the screen edge. Other overlays return to their usual size.
- Show the active controller's Select and Close glyphs. Preview rows spell out changes such as “0 to 1” in the game's pixel font.

## 0.1.0

- Added two named staffing layouts per kingdom run.
- Added per-building previews, worker and carrier shortfall estimates, demolition tracking and explicit application from the native worker panel.
